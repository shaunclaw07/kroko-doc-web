# Plan des nächsten Features

Diese Datei ist eine **Arbeitsdatei**: sie trägt Planung und Umsetzung des Features, an dem gerade
gearbeitet wird — die Entscheidungen aus dem Sparring, Abgesagtes mit Grund, die Schritte und ihren
Stand. Ist das Feature gebaut und abgenommen, wandert das Bleibende an seinen Ort (Regeln und
Fallen nach `AGENTS.md`, Begriffe nach `docs/domain-model.md`, Nachweise nach
`docs/e2e-nachweise.md`, Belege nach `docs/tier-quellen.md`) und diese Datei wird wieder geleert.

Gerade ist kein Feature in Arbeit.
